The first public release of Modkeel for desktop.

- **Get a mod** for the Minecraft version you play: the author's build when there is one,
  otherwise an older build that still runs there or a community port, each checked before
  you get it, with what was checked shown next to it.
- **Move a pack** to another Minecraft version: pick a launcher instance (Prism, Modrinth App,
  CurseForge, the Minecraft Launcher) or a mods folder. Every JAR is identified and resolved
  for the new version; with Prism the result becomes a new instance beside the old one, which
  is never touched.
- **Sign in with GitHub** (optional) to let Modkeel search more community forks.
- **Updates**: from now on the app tells you when a new version is out and updates itself.

Not signed by Microsoft or Apple yet: see the README for how to open it the first time.
