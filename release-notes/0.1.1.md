Modkeel for desktop is now open source, under the MIT license.

- The app's code is in this repository, and this release is the first one built here by
  GitHub Actions: each file carries a build provenance attestation, so you can check which
  commit and which workflow run made it (`gh attestation verify <file> -R Modkeel/app`, see the
  README).
- The engine inside is the `modkeel` command-line tool from PyPI, at the version pinned in
  `engine/requirements.txt` (0.1.7).
- Nothing else changes: if you have 0.1.0, this update only swaps in the openly built copy.
