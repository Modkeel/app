The Windows installer no longer carries a program that antivirus engines mistake for malware.

- On Windows the engine now runs inside python.org's official embeddable Python, whose
  `python.exe` and DLLs are signed by the Python Software Foundation, installed in the app's
  `engine` folder. It replaces a one-file executable that unpacked Python into a temporary
  folder each time it started, which three VirusTotal engines flagged on 0.1.1 as generic or
  machine-learning detections (false positives, reported to each vendor).
- macOS and Linux are unchanged. The engine is still the `modkeel` command-line tool from
  PyPI, at the version pinned in `engine/requirements.txt` (0.1.7).
