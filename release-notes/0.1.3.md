Getting a mod from a GitHub link now works on an ordinary PC.

- Paste a repository or branch link (for example a community port no one publishes a JAR for)
  and Modkeel builds it: without git installed (it downloads the branch from GitHub) and on the
  Java that Minecraft version needs (downloaded once if missing).
- Builds no longer hang in the app. Gradle was waiting on the app's connection to the engine.
- The engine is the `modkeel` command-line tool from PyPI, now 0.1.10.
